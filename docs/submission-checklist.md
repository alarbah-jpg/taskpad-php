# Submission checklist

- [ ] Repository is public, or the instructor is added as a collaborator
- [ ] Fresh download of the repo runs with `php -S localhost:8000 -t public`
- [ ] `docs/uml-usecase.pdf`, `docs/uml-class.pdf` (and `docs/uml-activity.pdf`) are in the repo
- [ ] `docs/uml/*.puml` sources are in the repo
- [ ] All screenshots are in `docs/screenshots/` (desktop, tablet, mobile)
- [ ] `docs/GroupEval.docx` is filled in and uploaded
- [ ] README has the names, run steps, and says where screenshots and diagrams live
- [ ] Member names are on every document and in the Canvas submission comments
- [ ] Canvas submission contains the GitHub repository URL
